# GridOne Studio landing

Authored design decisions from the user-selected reference and existing GridOne contracts. This is an existing-site update, not an interviewed new brand.

## User direction
“can u use the ... skill to update the landing page with better animations?”
“i wanted to see if the skill could produce a better mac studio style professional grade landing page”

## Brief topics
1. Vibe: authored interpretation: assured, dimensional, precise, product-led. Reference selected by user: Apple Mac Studio.
2. Journey: authored from PRODUCT.md: understand the promise, see a board fill and draw, understand score-to-square, explore viewer answers, see organizer control, choose a plan and create.
3. Energy: quiet monumental opening; build anticipation during fill; precise short score payoff; hands-on calm; confident close.
4. Feeling and remembered moment: board creation is the largest held chapter. A hundred squares acquire names, then the axes resolve.
5. Signature: names-before-numbers board assembly, followed by a score-to-square trace using the same demo digits. Existing fill is preserved and staged as the principal product demonstration.
6. Aesthetic: premium-minimal within Broadcast Glass, existing typefaces and tokens.
7. Structure: distinct product chapters, not a continuous flight. Inferred from reference and existing product-first brand.
8. Assets: existing real React viewer/organizer renders and labeled demo data. No generated imagery or paid services.

## Feeling curve (before score)
- Recognition: large promise beside a dimensional complete board and its phone view.
- Anticipation, then satisfaction: names appear across the held board, axis digits arrive last. PEAK.
- Clarity: true score digits connect to the winning coordinate and name.
- Agency: choose one of three viewer questions and inspect that real product render.
- Confidence: large organizer work surface with concise explanation.
- Resolve: factual pricing, concise disclosures, a held creation CTA.

Peak sentence: “The names filled the board, then the numbers clicked into place.”
Tell-someone sentence: “It is the site where you see your group’s board become ready for game day.”
Silence: the hero uses restrained depth, the viewer chapter has no ambient tint, and pricing is natural flow. No blank pinned intervals.

## Grammar and gate
Product chapters: normal brand header; asymmetric monumental hero; exactly one extended sticky assembly; short score explanation; a user-controlled viewer stage; wide organizer artifact; natural-flow factual pricing and held close. Bans: continuous flythrough, scroll hijacking, repeated zigzag feature rows, pinning on phone, animated invented scores.
This specific hybrid follows the requested existing brand: filmic one-shot wastes scroll, editorial folios add needless navigation, live surface forbids required marketing/header contracts, continuous world has no geographic meaning, typographic poster loses product proof, gallery gives objects equal weight, split stage forces a false comparison, rhythmic cutlist is too frantic.
Registry was empty: no prior rows to compare.

## Hero layer contract
Far: existing cardinal atmosphere, smallest movement. Mid: full board using real demo assignments, up to 24px travel. Near: real phone viewer overlapping board, up to 40px travel. Typography: stable, left anchored, actions accessible. Mobile: stacked compact composition, static depth; no pin.

## Reference evidence
https://www.apple.com/mac-studio/ inspected live: a large isolated product under a short headline; subsequent product chapters contrast image scale with restrained prose and selectable comparisons. Adapt scale, sequencing and agency, not Apple imagery, copy or palette.

## Integration
The existing React app remains the deliverable. Skill engine copies are retained unchanged as reference; production motion uses existing project hooks and feature-local helpers to preserve React lifecycle, token, reduced-motion and routing contracts.
Preflight: Node, ffmpeg, Playwright and Chrome available; optional libwebp and KIE key absent. Neither is required for the real component route.
