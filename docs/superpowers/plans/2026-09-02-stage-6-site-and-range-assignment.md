# Broadcast Glass Stage 6: Site Pages, Real Homepage Renders, Range Assignment

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every remaining route (articles, hub, login, paid, privacy, terms, 404) sits on the Broadcast Glass dark base; the homepage shows real viewer and organizer renders instead of primitive-built stand-ins; the organizer board editor regains range assignment (multi-select, drag, one label, seller, payment state including "not asked yet").

**Architecture:** A small `src/features/site/` layer (header, footer, page and article shells) replaces `components/layout/Layout.tsx` + `Header.tsx`; the twelve article pages and the hub keep their content and metadata verbatim and only swap wrapper and class names. The homepage's hero and organizer artifacts become lazy renders of the real `ViewerShell` and `BoardEditor` + `OrganizerIsland` with demo data, made `inert` so they are pictures, not controls. Range assignment is a selection mode inside `BoardEditor` with an inline apply bar; draft boards batch-upsert entry meta through a new `saveEntryMetaBatch` in the workspace's own `entryMetaService`; published boards route names through the existing `onAssignOpenSquares`.

**Tech Stack:** React 19, react-router, Tailwind v4 tokens from `src/design/tokens.css`, primitives in `src/design/primitives/`, Vitest (`--project unit`), Playwright chromium.

## Global Constraints

- Do not touch `hooks/`, `services/`, `functions/`, `workers/`, `supabase/`, Stripe, email, API shapes, `*Model.ts`, lifecycle/draft models, `utils/playerNameMatching.ts`, `context/AuthContext`.

- Exact product-truth strings preserved: `MONEY_BOUNDARY`, pricing details from `src/features/homepage/pricing.ts`, `Score updates about every minute`.
- DESIGN.md rules: anti-slop list, no icons (delete every `lucide-react` import and inline `<svg>` you touch), controls ≥ 44px, every link/button under `[data-base]` carries its own `focus-visible:ring-2 focus-visible:ring-action` (the global outline is stripped there), gold = committed states on cream / action on dark, cardinal = action on cream, live green only for in-progress games, score never shown without source and checked time.
- Copy vocabulary: never `pool`, `contest`, `league`, `player`, `guest` in user-facing copy you write. Existing article body copy is content and is left as is.
- No `window.location.reload()`.
- Homepage renders of real components must be `inert` and `aria-hidden` with an adjacent visually-hidden caption, must not fetch, must not register `beforeunload`, and must keep the homepage's first-viewport Playwright assertions passing.
